## Новое в пакете 3

### Редактор TypeScript
- Редактор больше не запускает TS как JavaScript. По кнопке «Запустить» код проходит через TypeScript-сервис Monaco: ошибки типов показываются под редактором, синтаксические ошибки блокируют запуск, затем скомпилированный JS запускается в песочнице (`src/components/lessons/code-playground.tsx`).
- Режим запуска определяется автоматически (`src/lib/playground/mode.ts`): JS, TS, HTML (JS-примеры с разметкой запускаются как страница), CSS или «только чтение» (примеры из нескольких файлов, с import/export, фрагменты `package.json`).
- Новый скрипт `npm run content:verify:playground` проверяет все 43 примера JS и TS (TS с проверкой типов в строгом режиме): 21 JS, 9 TS и 5 HTML запускаются, 8 помечены «только чтение», падающих нет. Он входит в `predeploy`.

### Проверка знаний
- Тест проверяется на сервере: `POST /api/quiz/submit` (`src/app/api/quiz/submit/route.ts`). Проходной балл 70% с округлением вверх (4 из 5), лимит 12 попыток в час на урок.
- Правильные ответы и пояснения больше не отправляются в браузер (`src/lib/quiz/public.ts`). Результат показывается после проверки: верно/неверно по каждому вопросу, правильный вариант раскрывается только после прохождения.
- `POST /api/progress/complete` не засчитывает урок, пока тест не пройден на сервере. Попытки хранятся в `quiz_attempts` (**новая миграция `supabase/migrations/009_quiz_attempts.sql`, её нужно применить**).
- Авторские тесты по 5 вопросов есть во всех 197 уроках с тестом (985 вопросов); проектные уроки теста не имеют. Тексты в `scripts/quizzes/*.py`, запись `python3 scripts/apply_quizzes.py`.
- Тест логики: `npm run test:quiz` (порог 70%, ответы не попадают в браузерную версию).

### Теория
- **Переписана теория во всех 213 уроках** (14 модулей): в среднем 226 слов на урок (было около 100), ни один урок не короче 1500 символов, повторяющихся блоков нет. Тексты лежат в `scripts/theory/*.py`, запись `python3 scripts/apply_theory.py`.
- В примерах Security заменено устаревшее: `csurf` (заброшен) на double-submit токен, `max` на `limit` в `express-rate-limit`.

## Как применить
1. Распакуйте архив поверх проекта (пути сохранены) или выполните `git apply fixes.patch`; удалите `scripts/judge-runner.mjs` (`deleted-files.txt`).
2. Примените миграцию `009_quiz_attempts.sql` в Supabase.
3. Запустите: `npm run content:verify`, `npm run content:verify:playground`, `npm run test:judge`, `npm run test:quiz`, `npm run build`.
4. Откройте урок с TypeScript и урок с тестом в браузере: это единственные части, которые я не мог проверить визуально.
